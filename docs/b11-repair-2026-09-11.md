## Repairs and numerical conventions

| Area | Previously failing cases | Result |
| --- | ---: | --- |
| Tensor reconstruction | 4 | Both byte/float and BGR/RGB paths set every output alpha byte to 255. |
| Depth histogram equalization | 2 | Histogram bins and cumulative counts use Int64; output ranks use exact integer division. |
| Depth placement | 1 | Merge uses offset-aware bounds and clips all four edges while retaining source coordinates. |
| Constant-series rendering | 15 | Constant automatic axes receive a finite nonzero extent. |
| Rectangle IoU, repaired before this change | 1 | Intersection multiplication widens before the product can overflow Int32. |

[TensorMatrix.cs](../sources/Imaging/TensorMatrix.cs) reconstructs an opaque
32-bit bitmap from three planes. RGB/BGR ordering remains as requested. Float
planes retain byte-scaled values in [0, 255] and truncate fractional parts.

[DepthTransform.Equalize](../sources/Imaging/DepthTransform.cs) retains the
inclusive empirical CDF convention:

```text
output(value) = floor(65535 * count(samples <= value) / population)
```

There is no subtraction of the first occupied CDF value. A nonempty constant
map therefore becomes 65535, and empty maps retain their shape. Widened counters
prevent bins from wrapping after 65,535 observations. Integer division also
avoids float rounding across output-code boundaries. Input samples are unchanged.

`DepthTransform.Merge` uses the placement origin plus its dimensions to find
the visible destination rectangle. Equal source and placement sizes copy samples
exactly. Overlapping self-merges read an original snapshot. Different sizes still
use the existing `DepthTransform.Resize` interpolation convention, followed by
placement and clipping. Empty/nonintersecting placements do nothing; negative
placement dimensions and a visible placement with an empty source are rejected.
Coordinate sums widen before addition, including fully off-screen placements.

[Figure.cs](../sources/Visualization/Figure.cs) expands an automatic axis only
when its combined finite data bounds coincide. The half-width is
`max(0.5, 0.05 * abs(value))`, computed in double and clipped to finite float
bounds. Multiple series contribute to the combined bounds before expansion.
Manual ranges retain their existing behavior. Repeated rendering does not keep
expanding the range.

Public signatures are unchanged. Implementation and documented numerical helpers
remain in their primary class files. The earlier
[selected imaging repairs](imaging-selected-repair-2026-09-11.md) resolved the
other 21 original B11 failures and added 477 passing cases.
